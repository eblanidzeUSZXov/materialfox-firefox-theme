# MaterialFox — зелёная Material You тема для Firefox

Зелёная тема в стиле Material You для Firefox: активная вкладка в форме листа, оформленная страница новой вкладки и плавные анимации.

[English version](README.md)

![Превью темы](assets/preview.png)

## Возможности

- Зелёная палитра Material You
- Активная вкладка в форме листа с зеркальным симметричным контуром
- Плавное переключение вкладок: лист проявляется и масштабируется
- Выбранная вкладка расширяется до 250px, остальные остаются компактными
- Микроанимации при наведении, нажатии, для favicon, кнопки закрытия и новой вкладки
- Оформление `about:newtab` и `about:home`
- Поддержка закреплённых вкладок и `prefers-reduced-motion`

## Установка

1. Открой в Firefox `about:profiles`.
2. Найди **Root Directory** используемого профиля.
3. Создай в этом каталоге папку `chrome`, если её ещё нет.
4. Скопируй в `chrome/` файлы:
   - `userChrome.css`
   - `userContent.css`
   - `leaf-tab.svg`
5. Открой `about:config`, прими предупреждение и установи:
   - `toolkit.legacyUserProfileCustomizations.stylesheets` в `true`
6. Перезапусти Firefox.

Файл `leaf-tab.svg` должен лежать рядом с `userChrome.css`, потому что стили ссылаются на него через `url("leaf-tab.svg")`.

## Примечания

- Тема использует `userChrome.css`, который официально не поддерживается Mozilla. После обновления Firefox может потребоваться поправить селекторы.
- Проверено на Firefox 158.0.1 под Linux. На Windows и macOS CSS должен работать так же; отличается только путь к профилю.
- Перед установкой пользовательских стилей сделай резервную копию профиля.
- Оформление новой вкладки из `userContent.css` применяется к `about:newtab` и `about:home`.

## Настройка

Основная палитра задана переменными `--md-*` в начале `userChrome.css`. Цвета заливки и обводки листа находятся в `leaf-tab.svg`.
